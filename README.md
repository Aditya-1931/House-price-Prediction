#  House Price Prediction 

## Project Overview
This project focuses on predicting house prices in Pune using Machine Learning. It uses the Linear Regression algorithm to estimate house prices based on different property features such as area, number of bedrooms, and location.

## Problem Statement
Estimating the correct price of a house can be difficult due to variations in location, property size, and other factors. This project aims to develop a machine learning model that predicts house prices based on available property information.

##  Aim
To build a Linear Regression model that predicts house prices in Pune using historical housing data.

##  Objectives
- To understand supervised machine learning.
- To analyze housing data.
- To train a Linear Regression model.
- To predict house prices based on input features.
- To evaluate the model's performance.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab / Jupyter Notebook

## Algorithm Used

Linear Regression

Linear Regression is a supervised machine learning algorithm used to predict continuous numerical values by identifying the relationship between input features and the target variable.

## Project Workflow
1. Collect the Pune housing dataset.

2. Load and explore the dataset.

3. Clean and preprocess the data.

4. Select input features and target variable.

5. Split the dataset into training and testing sets.

6. Train the Linear Regression model.

7. Predict house prices.

8. Evaluate model performance.

## Expected Output
The model predicts the estimated price of a house based on the given property details. It also evaluates prediction performance using suitable regression metrics.
